# 📸 SnapPop PhotoBooth

> A tactile, neo-brutalist AI photo booth powered by Google Gemini that captures moments, generates custom vintage postcards, and lets users print or download their memories.

[![Live Demo](https://img.shields.io/badge/Live%20Demo-Vercel-brightgreen?style=for-the-badge&logo=vercel)](https://snap-pop-photo-booth.vercel.app)
[![Built with Gemini](https://img.shields.io/badge/AI-Google%20Gemini-4285F4?style=for-the-badge&logo=google)](https://ai.google.dev)
[![React](https://img.shields.io/badge/Frontend-React%20%2B%20TypeScript-61DAFB?style=for-the-badge&logo=react)](https://react.dev)

---

## ✨ Features

- 📸 **Instant Snapshot:** Real-time web camera integration with countdowns and filters.
- 🎨 **Gemini AI Postcards:** Uses Google Gemini API to craft stylized, retro-themed postcards based on your photos.
- 🖨️ **Print & Download:** Export or print custom-designed postcards directly from the browser.
- ⚡ **Neo-Brutalist UI:** Tactile design aesthetics powered by modern styling components.

---

## 🛠️ Tech Stack

- **Frontend:** React, TypeScript, Vite, Tailwind CSS
- **AI Integration:** Google Gemini API (`@google/genai`)
- **Deployment:** Vercel
